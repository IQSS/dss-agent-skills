# Example: a minimal project

For a small utility, notes collection, website, or framework-driven project that does not need a larger research layout. Use `example-shared.md` for file purposes; preserve the framework's own structure.

```text
project/
├── CLAUDE.md
├── STATUS.md
├── TASKS.md
├── README.md
└── <files required by the work>
```

Use the instruction filename supported by the installed agent. Add only useful context files, language manifests, and commands. No runtime environment, credential file, or remote is needed merely because a folder has been scaffolded. If the project becomes more complex, extend the structure from its actual requirements rather than replacing useful existing organization.
