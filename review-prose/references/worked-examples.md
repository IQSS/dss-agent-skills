# Worked examples

These examples show how vague referents and compressed explanations make sentences hard to
understand. Read the examples alongside the surrounding passage when assessing a proposed rewrite.

| Written | Why it fails | Rewritten |
|---|---|---|
| The refusal is the policy. | *What* refusal, *whose* policy? Two definite articles, no antecedent for either. | That refusal is not a technical limit to work around; it is the provider saying you may not have those data that way. |
| An agent that can undo your undo has no undo. | Wordplay that does not parse. The agent does not undo your undo; it destroys the history you would have undone *with*. | If the agent can run them, the history you were relying on to reverse its work is the thing at risk. |
| Local removes the disclosure problem, not the permission one. | Two compressed concepts the reader was never handed, in a contrast frame. | Running the model yourself settles where the data went; it does not settle whether you were allowed to process it that way. |
| The browser is for finding the interface; the interface is for the collection. | "The collection" must be unpacked, and the handoff of "interface" silently carries the argument. | Use the browser to work out how the site serves its data, then write a script that asks for it the same way. |
| The entry is written when the file is, or it is fiction. | *Fiction* has no referent. | Write the entry in the same step that saves the file, or it will be written from memory. |
| Plain `git` gives you the repository. It does nothing about placement. | Placement of *what*? A bare abstract noun, so no article gives it away. | Plain `git` can version the files, but it cannot put them where each tool expects to find them. |
| The trade is depth for breadth. | Depth of what, breadth of what? Six words standing in for the sentence that follows them. | You get a deeper fit with that one vendor, and give up the ability to switch. |
| That feeling is the symptom, not the check. | Symptom of what, check of what? Neither noun identifies the action or concern being discussed. | If a sentence strikes you as quotable, treat that as a reason to look at it harder, rather than a reason to keep it. |

## The minimal pair

The clearest way to see shape 2. Same repeated noun, same length, opposite verdicts:

| | |
|---|---|
| **Fine** | ...is decoration, **and** decoration in this kind of writing **reads as** sales copy. |
| **The defect** | ...is decoration**;** decoration in this register **is the** ad copy. |

The first coordinates with "and", so the logical relation is stated, and closes on "reads as", a verb
of effect. The second juxtaposes with a semicolon, leaving the reader to infer the relation, and then
closes on "is the ad copy", an identity claim whose definite article has no antecedent.

## What passes

The rule is not "no rhythm" and not "no semicolons". These are fine, because both halves are literal
and complete and nothing needs reconstructing:

- Claude Code reads `CLAUDE.md`; Codex reads `AGENTS.md`.
- The agent writes the scripts; you own the model.
- Agreement rules out implementation error, not specification error.
- Quote the terms; do not summarize them.

The difference is whether the reader takes the meaning at once or has to work it out.

## The tell

In every instance above, **the plain sentence already came immediately before**. The paragraph had
made its point, and the closing line said the same thing again in a more memorable form. So the
cheapest question is not "is this sentence clear on its own" but *"does the sentence before it
already say this?"* The detector prints the previous sentence for exactly this reason.
